Project Description

The CyberSecurity Awareness Chatbot is a Windows Forms application developed in C#. It helps users learn about cybersecurity through an interactive chatbot, a task assistant, a cybersecurity quiz, and an activity log.

The application uses a MySQL database to store cybersecurity tasks and reminders.
